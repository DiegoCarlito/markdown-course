# Markdown Básico

## Títulos
Os títulos ajudam a organizar a estrutura do seu documento. Para criar um título, use o símbolo cerquilha (`#`) seguido de um espaço.

```markdown
# Título 1 (Maior)
## Título 2
### Título 3
#### Título 4
```

## Formatação de Texto
Você pode destacar palavras ou frases facilmente:

```markdown
**Texto em negrito** (Use dois asteriscos)
*Texto em itálico* (Use um asterisco)
~~Texto tachado~~ (Use dois tis)
```

**Exemplo renderizado:**
**Texto em negrito**, *Texto em itálico*, ~~Texto tachado~~.

## Listas
Criar listas é muito intuitivo.

**Listas não ordenadas:**
```markdown
* Item 1
* Item 2
  * Subitem
```

**Listas ordenadas:**
```markdown
1. Primeiro passo
2. Segundo passo
```

## Código e Links

**Adicionar Links:**
```markdown
[Clique aqui](https://gitlab.com)
```

**Blocos de Código:**
Utilize três crases (\`\`\`) para destacar trechos de código ou comandos na sua documentação:

```markdown
\```bash
git clone https://gitlab.com/...
\```
```
