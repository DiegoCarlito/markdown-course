# Curso de Markdown

Bem-vindo ao curso básico de Markdown! O foco deste repositório é ensinar como escrever e padronizar documentos usando a linguagem Markdown. 

## O que é Markdown?
O Markdown é uma linguagem de marcação leve e muito fácil de ler. Ele permite formatar textos usando apenas caracteres comuns do teclado, sem a necessidade de editores complexos.

- **Fácil de escrever** e aprender.
- **Amplamente utilizado** em documentação de código e blogs.
- Converte texto simples em HTML bem estruturado.

## Ferramentas Recomendadas
Para escrever e visualizar Markdown, recomendamos o **Visual Studio Code (VS Code)**.
- **Download:** [code.visualstudio.com](https://code.visualstudio.com/)
- **Setup:** Basta baixar e instalar. Abra qualquer arquivo `.md` no editor e pressione `Ctrl + Shift + V` (ou `Cmd + Shift + V` no Mac) para abrir a janela de pré-visualização.
